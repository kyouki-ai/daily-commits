# daily-commits

Репозиторий, в котором каждый день появляется коммит — автоматически.

## Как это работает

`daily.ps1` запускается Планировщиком задач Windows каждый день в 21:00 и:

1. коммитит незакоммиченные изменения, если они есть;
2. если за сегодня коммита нет — дописывает в `journal.md` строку с датой и номером дня и коммитит её;
3. пушит в GitHub.

Если компьютер в 21:00 был выключен, задача догоняет при следующем включении.

## Настройка

Задача называется `daily-commits`. Проверить:

```powershell
Get-ScheduledTask -TaskName 'daily-commits' | Select-Object TaskName, State
```

Запустить вручную:

```powershell
Start-ScheduledTask -TaskName 'daily-commits'
```

Результат каждой попытки — в `daily.log`.

## Требования

- git в PATH;
- вход в GitHub CLI (`gh auth status`) — из него берётся токен для пуша.
